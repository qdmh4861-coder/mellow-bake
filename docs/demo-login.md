# 데모 로그인

이 기능은 포트폴리오용 브라우저 시연입니다. 실제 인증·회원가입·서버 권한 검증을 제공하지 않습니다. 브라우저 검사와 세션은 조작할 수 있으며 실제 고객 정보에 사용하면 안 됩니다.

## 최초 설정

1. 프로젝트 터미널에서 `node scripts/setup-demo-auth.mjs` 실행.
2. 12자 이상의 전용 데모 비밀번호를 숨김 입력으로 두 번 입력. 실제 서비스에서 쓰는 비밀번호를 재사용하지 마세요.
3. Vite 개발 서버 재시작(`npm.cmd run dev`).
4. `/login`에서 `demo@mellowbake.test`와 직접 설정한 비밀번호로 로그인.

원문 비밀번호는 저장·출력하지 않습니다. 무작위 salt와 PBKDF2 검증값만 Git에서 제외되는 `.env.local`의 `VITE_DEMO_AUTH_SALT`, `VITE_DEMO_AUTH_VERIFIER`에 저장됩니다. 기존 다른 환경변수는 유지됩니다. Vite 변수는 빌드에 포함되므로 검증값도 비밀이 아니며 실제 서버 인증을 대체하지 못합니다. 설정 없이 로그인하면 설정 필요 안내가 표시됩니다. 재설정도 같은 명령을 실행합니다. 배포 시에는 설정 후 다시 빌드해야 합니다.

## 동작

- 로그인 성공 시 마이페이지로 이동. `sessionStorage`의 데모 표시만 사용하고 비밀번호는 저장하지 않습니다.
- 같은 탭 새로고침과 이동 시 유지, 12시간 뒤 만료. 탭을 닫으면 세션 종료.
- 로그아웃 시 로그인 표시만 삭제. 찜·리뷰·문의 등 기존 브라우저 데이터는 보존.
- 마이페이지 회원 기능, 찜 목록, 리뷰 작성은 로그인 필요. 공지·FAQ·전체 공개 리뷰는 비회원 열람 가능.
- 하나의 데모 계정이 기존 브라우저 찜·문의 및 기존 리뷰 작성자 기록을 재사용. 실제 회원별 서버 데이터 격리는 제공하지 않습니다.
- 회원가입은 입력 검사만 하며 계정 생성·자동 로그인은 하지 않습니다.
