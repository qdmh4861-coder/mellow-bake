## 신규 상세 공통 보완 자료

소금빵을 제외한 각 상품은 현재 한 줄 설명만 있어, 상품별 추가 사진·상세 원재료 목록·알레르기·중량/용량·보관 방법·소비기한·배송 조건이 필요합니다. 확인되지 않은 정보는 임의로 만들지 않았습니다. 재료 소개는 기존 설명 범위만 사용합니다.

장바구니 서버/화면은 기존 프로젝트에 없어 신규 상세의 장바구니 버튼은 기존 소금빵처럼 준비 중 안내를 표시합니다. 실제 주문 저장은 하지 않습니다.

## 상세 구성 확장

신규 상세는 상단 상품 정보 → 상품 소개 → 재료 → 보관 방법 → 리뷰 → 추천 상품 순서로 구성했습니다. 소금빵 기존 파일은 그대로이며, 시나몬롤·불고기 샌드위치도 이번 확장 대상에서 제외해 현재 디자인을 유지했습니다.

재료는 각 상품의 기존 설명에서 명시된 항목만 표시합니다. 전체 원재료·함량·알레르기는 확인 중으로 표시합니다. 보관 정보나 실제 후기는 자료가 없어 만들지 않았습니다.
