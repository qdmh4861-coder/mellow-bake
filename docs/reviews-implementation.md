# 리뷰 페이지 및 상품별 연결

## 적용
- REVIEW 경로 /reviews 유지. 기존 헤더 REVIEW 링크로 접근.
- PC4열 / 태블릿2열 / 모바일1열. 흰 카드, 크림 테두리, 골드 별점, 본문, 닉네임, 상품명, 날짜 표시. 긴 본문은 원본을 유지하며 카드 행 높이와 하단 정보를 정렬.
- 전체/사진 첨부/일반 필터, 상품 선택, 최신순/별점 높은순/낮은순, 페이지네이션, 카드 전체 클릭으로 해당 상품 상세 이동.
- 88개 등록 상품 ID를 기존 slug 기준83개 동일상품 그룹으로 구분. 각 그룹4개, 총332개 시연용 예시. 기존 공개 화면 예시10개 문구·닉네임·날짜·이미지 재사용. 상품별 리뷰 개수/경로는 review-product-counts.csv.

## 실제 저장 리뷰 보호
- localStorage 리뷰와 이미지 삭제·초기화·시드 저장 없음. 예시는 읽기 전용 정적 데이터.
- getPublicReviews/getMyReviews/getProductReviews 기존 실제 저장 데이터 전용 동작 유지.
- 공개 목록/신규 상세는 별도 display 조회 함수 사용. 해당 상품의 실제 저장 리뷰가 있으면 예시 대신 표시.
- 예시는 실제 고객/구매 후기로 표시하지 않고 카드별·화면에 시연용 표시. 작성한 리뷰/수정/삭제 대상에 예시가 들어가지 않음.

## 상세 연결 및 보호
- 85개 미완성/바스크 상세의 리뷰 연결만 보완. 기존 상세 리뷰 스타일은 수정하지 않음.
- 소금빵·시나몬롤·불고기 샌드위치는 기존 피그마 시안 리뷰와 이미지를 유지. 기존 상품별 /reviews?productId=... 링크에서 해당 상품 리뷰를 볼 수 있음. 이 세 상세 내부의 고정 시안 리뷰를 동적 카드로 교체하지 않았음.
- 바스크의 다른 정상 영역, 상품 정보/가격, HOME/MENU/STORE/ABOUT/검색/장바구니/찜/로그인/헤더/푸터 변경 없음.

## 이미지
- 기존 리뷰 사진/상품 사진이 있으면 우선 유지. 사진이 없는 예시는 같은 상품의 기존 연출 이미지 영역으로 표시하고 실제 고객 사진으로 주장하지 않음.
- 전용 리소스: src/assets/reviews/strawberry-shortcake.png, src/assets/reviews/peach-yogurt.png. 바스크는 public/images/바스크치즈.png의 해당 상품 장면4개.
- matcha-strawberry-roll.png는 등록 상품과 정확히 일치하는 이름이 없어 임의 연결하지 않음.
- 이미지 파일 자체 신규 생성/수정 없음. 표시할 상품 이미지 누락 없음. 다만 전용 리뷰 사진 추가 권장 대상 80개 그룹은 review-photo-requests.csv에 기록. 권장 파일만 추가하면 자동 게시되는 것이 아니며 예시 photos 필드 또는 실제 리뷰 첨부 데이터에 연결해야 함.
- 사용자 리뷰 사진이 없거나 로드 실패하면 해당 상품 이미지로 표시하며, 임의의 다른 상품으로 대체하지 않음.
