# HOME 원본 자료 목록

현재 상품 사진·매장 사진을 대체 이미지로 사용하지 않았습니다. 화면의 점선 영역은 아래 원본이 필요한 위치입니다.

- 메인 비주얼: 케이크·디저트 이미지 1개, 로고 및 장식/캐릭터 투명 이미지
- BEST MENU: 상품 이미지 4개, 상품명·설명·가격
- NEW MENU: 상품 이미지 4개, 상품명·설명·가격
- 시즌 배너: 완성 배너 또는 디저트 이미지와 정확한 문구
- NEW ARRIVALS: 상품 이미지 4개, 상품명·설명·가격
- 매장 소개: 사진 1개, 캐릭터 장식, 브랜드 소개 문구
- CUSTOMER REVIEW: 사진 4개, 실제 리뷰 본문·작성자 정보
- 매장 안내: 실내 사진 1개, 주소·운영시간·지도 링크
- 헤더/푸터: 정확한 메뉴·사업자 정보·연락처·정책 및 연결 주소
- 디자인 공통: 고해상도 Figma 내보내기, 사용 폰트, 하트·꽃·리본 등 원본 장식

이미지 슬롯은 src/pages/Home.jsx의 ImageSlot 컴포넌트로 표시됩니다. 원본 제공 시 해당 호출 위치를 실제 이미지로 교체할 수 있습니다.
축소 참고 이미지로 판독되지 않는 문구와 정보는 입력 예정으로 표시했습니다. 현재 장식은 CSS/SVG 및 문자 도형으로 재현했으며, 원본 이미지와 완전히 동일한 장식은 아닙니다.
